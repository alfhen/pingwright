Server container

Sends a Meta pixel Purchase hit with an event ID, then a hit to the mock server container host, which --server-container sends to the local container instead. ?email= is the email of the first hit. ?extra=1 adds a hit with an unrelated event ID and a fake email, and a hit to /data, a path no decoder knows. ?delayMs= loads the consent banner, sends the hits once, when the first consent answer is given, and asks the stand-in container to wait that long before it sends on.
