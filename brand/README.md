# Brand

The Pingwright mark is one tracking pixel inside four corner brackets. The pixel sits 4 units up and to the right of centre, as if it was just caught.

## Files

| File | Use |
| --- | --- |
| `mark.svg` | The mark on light backgrounds. |
| `mark-dark.svg` | The mark on dark backgrounds. |
| `mark-mono.svg` | One colour. It uses `currentColor`. |
| `lockup.svg`, `lockup-dark.svg` | Mark and wordmark, for light and dark backgrounds. |
| `favicon-16.svg`, `favicon-32.svg` | Drawn on the pixel grid for small sizes. Don't scale the 64-unit mark down for these. |
| `favicon.ico` | 16 and 32 px, for browsers that ask for `/favicon.ico`. |
| `social-preview.png` | The 1280×640 GitHub social preview. `social-preview.svg` is its source. |

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Graphite | `#182E38` | Brackets and text on light backgrounds; dark background. |
| Teal | `#087F78` | The pixel on light backgrounds. |
| Light | `#F4F7F7` | Brackets and text on dark backgrounds. |
| Mint | `#69D6C2` | The pixel on dark backgrounds. 8:1 contrast on graphite. |

## Rules

- Keep the pixel offset. A centred pixel is a different mark.
- Don't round the bracket corners, add gradients or outline the mark.
- Leave at least 10 units of space around the mark on its 64-unit grid.

## Wordmark

The wordmark is "pingwright" in Jost Medium, converted to outlines. The tagline in the social preview is Jost Regular. Jost is by Owen Earl (indestructible type\*) under the SIL Open Font License 1.1. The repo holds only the outlines, not the font.
